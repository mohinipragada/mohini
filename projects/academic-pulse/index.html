UI Design Project

Academic Pulse – Student Portal

A modern student portal UI designed for university students to manage their academic activities in one place. The project has two screens: a Student Login page and a Student Dashboard.

  • Google Stitch
  • Figma
  • HTML
  • CSS
  • JavaScript

🔐 Student Login Page

  • Student ID / Campus Email
  • Password
  • Remember this device
  • Forgot Password
  • University Campus SSO
  • Face ID / Fingerprint Login

📊 Student Dashboard

  • Student profile
  • Attendance percentage, pending assignments, active courses and GPA
  • Today's schedule
  • Subject-wise attendance
  • Assignments
  • Campus announcements
  • Bottom navigation
