Web Design Project

CampusPortal: Student Dashboard (EduPulse)

  • Built with HTML/CSS
  • Made with Google Stitch
  • Made with Claude
Description
A responsive academic dashboard where students can see attendance, pending assignments, courses, CGPA and the day's class schedule in one place.
Features
Summary stat cards, today's schedule, attendance bars, assignment tracker, announcements.
Technologies
  • HTML
  • CSS
  • JavaScript
GitHub Repo Live Demo

CampusPortal Case Study

  1. Problem

    Students check attendance, assignments, grades and timetables in different places, so it is easy to miss a deadline or fall below the attendance limit.

  2. User

    A college student who checks their phone between classes and needs today's information in a few seconds.

  3. Process

    I listed what a student looks at every day, generated layout ideas in Google Stitch, then built and refined the page in HTML and CSS with help from Claude.

  4. Solution

    A mobile-first dashboard with summary cards, today's schedule with live class status, subject-wise attendance bars, an assignment tracker and announcements.

  5. Result

    Everything a student needs for the day is on one screen, with urgent items like pending assignments and low attendance clearly highlighted.
